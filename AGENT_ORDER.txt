SECTION 3 — RÈGLES MÉTIER CRITIQUES
================================================================================

1. COMMANDE INVITÉ (GUEST CHECKOUT)
   - La création de compte N'EST PAS obligatoire pour commander
   - Un client peut passer commande en fournissant uniquement :
     nom, email, téléphone, adresse de livraison
   - Dans ce cas Order.user = NULL en base de données
   - Les commandes invitées ne sont pas visibles dans /api/orders/mine/
   - Un invité peut retrouver sa commande via email + téléphone
   - L'admin voit TOUTES les commandes (invités inclus)

2. GESTION DU STOCK
   - Vérifier le stock AVANT de créer la commande
   - Refuser la commande si le stock est insuffisant
   - NE PAS décrémenter le stock à la création de commande
   - Décrémenter le stock UNIQUEMENT après confirmation de paiement (webhook SUCCESS)
   - Si stock = 0 : afficher le label "Rupture de stock" sur le produit
   - Si stock = 0 : désactiver le bouton d'ajout au panier (disabled)
   - Interdire toute quantité négative dans les OrderItems

3. SUPPRESSION DE PRODUITS
   - La suppression physique en base est STRICTEMENT INTERDITE
   - Utiliser uniquement is_active = True / is_active = False
   - Produit avec is_active = False : invisible sur le site public
   - Produit avec is_active = False : visible dans l'interface admin

4. PERSONNALISATION
   - Si Product.is_customizable = True : afficher le champ texte de personnalisation
   - Afficher Product.customization_hint comme placeholder du champ
   - Upload de fichier (logo) optionnel même si is_customizable = True
   - Formats de fichier acceptés : jpg, jpeg, png, pdf, ai, svg
   - Taille maximale upload : 10 MB
   - Stocker le fichier sur Cloudinary et sauvegarder l'URL dans OrderItem.custom_file
